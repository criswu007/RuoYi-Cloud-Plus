## 1. 使用原则

- **批次基线**：以表名后缀 `_nj_20260317` 作为本批次历史基线标识（见正式报告）。
- **字段分层**：
  - “可直接进入接口”：可按原值透出为接口字段（仍需保留可空/缺失等约束提示），不依赖额外解释规则即可被调用方基本使用。
  - “需转换后进入接口”：进入接口前需要补充解释、类型转换、或跨表关联才能满足接口语义；否则仅能暴露“原始编码/原始值”，不宜承诺可读含义。
  - “当前无法直接支撑的接口能力”：在本批次纳入的 8 张表范围内未形成可直接支撑的事实链或操作痕迹，需后续领域包补盘。
  - “待需求澄清字段”：字段已存在于证据/报告，但缺少业务口径或歧义较大，接口侧需先澄清再冻结入参/出参语义。
- **建议接口位置用语**：统一使用 `列表字段 / 详情字段 / 查询条件 / 树结构字段 / 关联查询字段 / 治理字段` 表达，便于直接对接后续接口设计。
- **关于 `tmp_addr_set_segm_nj_20260317` 的边界（必须声明）**：
  - 该表在本批次被归入“标准地址核心”仅为“标准地址主链路事实闭环”的盘点需要，用于确认“安装地址到标准地址”的挂接现状。
  - 其更完整的关系含义、资源侧解释与后续接口输入，应在后续“安装地址与资源关系”领域包中补齐，不应在本清单中将其扩展为标准地址本体属性或资源关系全量能力（见正式报告与任务体系设计）。
- **关于 `[EMPTY RESULT]` 与“输出为空”**：
  - 证据中出现 `[EMPTY RESULT]`（例如重复检查 top20）时，不应直接等价为“绝对 0”，仅可在“本次证据口径下未检出样本”范围内表述（正式报告已给出同类结论）。
  - 关联缺失检查“输出为空”的场景（例如区域挂接缺失检查）不得强写为 0，除非正式报告已明确允许（正式报告明确要求后续以统一计数格式再确认）。

## 4. 当前无法直接支撑的接口能力

> 说明：以下结论仅针对本批次纳入“标准地址核心”的 8 张表与已采集证据输出；不等价于“历史库绝对不存在”，仅表示“当前盘点事实不足以支撑接口冻结”。

- **标签体系**：证据材料与正式报告未出现与“地址标签/标签字典/标签关系”相关的表与字段输出，当前无法直接支撑“按标签检索/标签治理/标签继承”等接口能力。
- **合并/拆分显式操作痕迹**：证据材料与正式报告未采集到“地址合并/拆分”操作日志、版本链、或显式关系痕迹字段，当前无法直接支撑“合并/拆分历史追溯、冲突解释、回滚”等接口能力。
- **规则引擎与监控任务**：任务体系设计与正式报告未纳入规则引擎/监控任务相关表与证据输出，当前无法直接支撑“规则触发、巡检任务、异常监控指标”等接口能力。
- **异常地址与工单链路**：证据材料与正式报告未出现“异常类型、工单、处理状态、关联链路”等表或字段输出，当前无法直接支撑“异常地址治理闭环、工单追踪”等接口能力。
- **网格归属字段**：任务体系设计明确 `网格主数据` 与 `网格关系与归属` 当前为缺口包（spec 第 7.2 节），本批次证据与报告中未形成标准地址到网格的事实链路，当前无法直接支撑“网格归属查询/按网格聚合/网格治理”等接口能力。

## 5. 待需求澄清字段

> 本节为“字段存在但口径未冻结/歧义较大”的项；若不先澄清，接口设计阶段容易产生不可逆的入参/出参约束。

- `segm_type`：枚举含义缺失，需明确其与 `segm_addr_type` 的映射关系，以及是否允许接口只暴露 code 而不提供可读解释（正式报告）。
- `parent_segm_id`：空值语义需区分“根节点”与“缺失父节点”；同时需明确其实际父子连接键口径，当前证据尚不能冻结连接规则（正式报告）。
- `region_id`：区域关联缺失检查“输出为空”不等价于缺失为 0；需要补充统一计数格式或 SQL 证据后才能冻结“强一致”结论（正式报告）。
- `station_id`：已存在 `missing=1` 的关联缺失，需要明确接口层的返回策略（例如返回空、返回占位、或返回治理提示）与治理入口承载位置（正式报告）。
- `service_region_id`：字段存在但未解释语义，需澄清与“区域/公司归属”的口径边界（证据字段清单仅证明存在）。
- `addr_in_type` / `addr_in_type_ftth` / `ftth_pon_type` / `addr_in_type_lan`：均为编码字段但缺少值域解释，需明确是否有字典表可解释、以及接口是否允许“仅透出原始编码”（证据字段清单 + 正式报告未解释）。
- `cover_num`：类型为 `varchar(64)`，需明确其是否为数值、单位口径、以及异常值处理策略后再作为筛选条件或统计口径（证据字段清单）。
- `tmp_addr_set_segm_nj_20260317.segm_id`：挂接未命中规模大（`missing=1290542`），需拆分原因并明确兜底策略；同时需明确该表的临时归位边界，避免在“标准地址核心”接口中固化安装地址域的长期契约（正式报告 + spec）。
