# 线上最新非备份表结构手册

## 1. 使用说明

- 本手册覆盖当前 `ftth_cloud_address` catalog 下所有 `table_name NOT LIKE 'bak%'` 的非备份表。
- `ADDR_SEGM` 与 `ADDR_SET_SEGM` 的字段结构按全量 `information_schema` 盘点，数据值域/空值观察采用 `crc32(主键) % 100 = 0` 的 1% hash sample。
- 有明确外部来源的字段，`取值来源` 直接写具体表/字典；枚举编码字段尽量列出全量候选值。
- 字符串 ID 字段只写来源，不展开具体值；时间类字段与普通字符串字段不展开具体取值。
- 来源仍有歧义的编码字段，在备注中显式标注“来源待确认”或“混合引用”，避免误判为已冻结口径。
